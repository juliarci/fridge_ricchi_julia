# Frigo – gestion des produits d'un réfrigérateur

Application web réalisée en 2024 dans le cadre de ma formation.
Elle affiche le contenu d'un frigo et permet d'ajouter ou de retirer des produits,
en communiquant avec une API REST fournie pour le cours.

## Fonctionnalités
- Liste des produits du frigo, avec leur quantité
- Ajout d'un produit (requête POST)
- Suppression d'un produit (requête DELETE)

## Technologies
Vue 3 · Vuetify 3 · Vue Router · JavaScript · API REST (fetch) · Vite

## Lancer le projet
npm install
npm run dev
